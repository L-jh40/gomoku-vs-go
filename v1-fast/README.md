# 黑白混合规则对弈 AI

## 规则概述

这是一个融合五子棋与围棋规则的混合对弈系统:

| 角色 | 规则 | 目标 |
|------|------|------|
| **黑棋** | 五子棋 (仅禁手限制): 三三、四四、长连三种禁手 | 形成 5 连获胜 |
| **白棋** | 围棋: 可吃黑棋组 (无气即提), 白棋不可被吃 | 吃光黑棋获胜 |
| **棋盘** | 默认 15 路 (可调 19 路) | |

### 核心机制

- **黑棋**下子不参与吃子, 仅按五子棋规则判胜负.
  - **三三**: 一子同时形成 2+ 活三 (此子为公共构成子)
  - **四四**: 一子同时形成 2+ 四 (活四或冲四)
  - **长连**: 形成 6+ 连续同色子
  - 正好 5 连 = 胜利 (即使同时构成禁手也判胜)
- **白棋**下子后, 检查所有相邻黑棋组, 气数为 0 的组立即被提.
  - 白棋自身不会被吃, 可在任意空位下子 (包括"无气"位).
  - 终局: 黑棋连五获胜; 白棋因不可被吃, 在封锁所有黑棋连五路线后，可填满棋盘吃光黑棋. 因为黑棋禁手，尽管封锁所有路线后一直pass可使黑棋无法获胜, 白棋有可能落子解除黑棋禁手使黑棋获胜. 然而, 此时白棋总有办法可以在阻挡黑棋连五的基础上填满棋盘, 故只要填满所有路线, 可判定白棋获胜 (可以关闭自动判定).

### 参考

- Gomoku 禁手判定: 参考 ZZRR0/GoBang、COMP7015-gomoku-ai-adversarial-search
- 围棋气数/吃子: 参考 pyDLGO、Tinygo 的组与气计算
- 规则插件化思路: 参考 ChessMaker 的可调整规则引擎

## 如何运行 (面向非编程用户)

### 第一步: 确认电脑已安装 Python

1. 打开"终端" (Mac) 或"命令提示符/PowerShell" (Windows):
   - **Windows**: 按 `Win + R`, 输入 `cmd`, 回车
   - **Mac**: 打开"启动台" → "其他" → "终端"
2. 在黑色窗口里输入以下命令并回车:

   ```
   python --version
   ```

   或 (Mac/Linux):

   ```
   python3 --version
   ```

3. 如果显示类似 `Python 3.12.x` 或更高版本, 说明已安装. 如果提示"找不到命令", 请前往 [python.org](https://www.python.org/downloads/) 下载安装 Python 3.12+, 安装时 **务必勾选 "Add Python to PATH"**.

### 第二步: 安装依赖库

在终端里输入以下命令并回车 (只需执行一次):

```
pip install numpy
```

> 说明: tkinter 通常随 Python 自动安装, 一般不需要额外操作. 如果启动 GUI 时提示找不到 tkinter, Mac 用户可运行 `brew install python-tk`, Windows 用户重新安装 Python 时勾选 "tcl/tk" 选项.

### 第三步: 用 VSCode 打开项目

1. 下载并安装 [VSCode](https://code.visualstudio.com/) (免费).
2. 打开 VSCode, 按 `Ctrl + O` (Windows) 或 `Cmd + O` (Mac), 选择 `gomoku_go_hybrid` 文件夹.
3. 在 VSCode 中打开任意一个 `.py` 文件 (如 `main.py`), 如果右下角提示安装 Python 扩展, 点击"安装".
4. 在 VSCode 中打开终端: 菜单栏 → "终端" → "新建终端" (或快捷键 `` Ctrl + ` ``).

### 第四步: 运行程序

在 VSCode 底部的终端窗口中, 输入以下命令之一并回车:

**方式 A — 图形界面 (推荐):**

```
python main.py
```

> Mac 用户如果 `python` 不行, 请用 `python3 main.py`.

运行后会弹出一个棋盘窗口:
- **默认黑白都由 AI 自动下** — 你可以观战.
- 窗口右侧有两个复选框 **"黑棋 AI"** 和 **"白棋 AI"**:
  - **取消勾选** → 该方改为人类手动下, 用鼠标点击棋盘空位即可落子.
  - **重新勾选** → 该方改回 AI 自动下.
  - 切换是实时的, 不需要重开程序.
- 点击 **"黑 AI 立即下"** / **"白 AI 立即下"** 按钮, 可手动让 AI 立即走一步.
- 点击 **"新对局"** 按钮重置棋盘.
- AI 每步思考时间显示在右下角 (精度 2 位小数, 如 `0.58s`).

**方式 B — 19 路大棋盘:**

```
python main.py --size 19
```

**方式 C — 命令行模式 (纯文字, 无图形界面, 黑白 AI 自动对弈):**

```
python main.py --cli
```

> 这种模式下不能手动下子, 只能看 AI 对弈结果. 输出每一步着法 + 棋盘文字图.
>
> 可用 `--max-moves 100` 限制最大手数, 如: `python main.py --cli --max-moves 100`.

### 常见问题

| 问题 | 解决方法 |
|------|----------|
| 提示 `ModuleNotFoundError: No module named 'board'` | 确保终端当前路径在 `gomoku_go_hybrid` 文件夹内 (用 `cd` 命令切换到该文件夹) |
| 提示 `ModuleNotFoundError: No module named 'numpy'` | 运行 `pip install numpy` |
| GUI 窗口没弹出 | 确保用的是 `python main.py` 而非 `python main.py --cli` |
| Mac 上 `python` 找不到 | 改用 `python3` |
| VSCode 终端里无法输入命令 | 确保选中了底部的终端窗口 (不是代码编辑区) |

## AI 策略说明

### 候选范围

- 黑棋、白棋的搜索点位都不包含白棋领地。
- 黑棋不搜索蓝叉（禁手/无气位置）。
- 白棋可以搜索禁手位置，但不搜索黑棋落子后无气的位置。
- 没有红色位置时，选择横竖斜方向上与棋子、白棋领地、棋盘边缘距离最大的空格。

### 计分

- 实心圆（黑棋连五点位）：不计分，由最高优先级 if-else 直接处理。
- 三角形（落子后形成黑棋活三+冲四或活四的点位）：625 分。
- 大圆圈（落子后形成黑棋冲四或活三的空格）：125 分。
- 小圆圈（落子后形成黑棋眠三或眠二的空格）：25 分。
- 红点（落子后形成黑棋眠二的空格）：1 分。
- 领地（无法参与黑棋连五的空格）：-1 分；黑棋领地同样按 -1 分。
- 黑棋块分数：`A * (1 - (1/2)^n)`，其中 `A` 为该黑棋块瞬间消失时减少的分数，`n` 为该块的气数。
- minimax 中黑棋使分数尽可能高，白棋使分数尽可能低。

### 黑棋 AI

1. 有实心圆时，直接落子其中一个实心圆。
2. 有三角形时只在三角形中搜索：
   - 若某个三角形落子后产生的实心圆，白棋在 `minimax 深度 + 2` 内无法消除，则直接落子该三角形。
   - 若全部三角形白棋都能消除，则在这些三角形中开始 minimax。
3. 没有实心圆/三角形时，在红色位置开始 minimax。
4. 没有红色位置时，选择与棋子、白棋领地、棋盘边缘距离最大的空格。

### 白棋 AI

1. 有实心圆或三角形时，候选点包括：
   - 所有实心圆和实心三角形位置；
   - 组成攻势（活四、冲四、活三）的黑棋块中，只剩一气的块的气所在位置。
2. 筛选落子后能确保消除所有实心圆的候选点。
3. 判断黑棋下一步能否形成实心圆或三角形；若能，用同样的“清除实心圆”算法继续搜索，搜索深度为 `minimax 深度 + 2`。
4. 在深度内能清除完实心圆的位置中落子；若不止一个，开启 minimax。
5. 若没有任何能清除实心圆的位置，则投子认负；勾选“取消投子认负”时，优先在一个实心圆落子，没有则在一个三角形落子。
6. 没有实心圆/三角形时，在红色位置开始 minimax；没有红色位置时选择最远空格。

### minimax

- 黑棋与白棋共用迭代加深 minimax + alpha-beta 剪枝。
- 搜索层数可选 0/2/4/6/8，默认 2；还可设置“最短搜索时间”。
- 手动点击“AI 立即落子”会打断搜索，并返回上一个已完成偶数层的最优解。

## 简单性能

| 指标 | 15 路 | 19 路 |
|------|-------|-------|
| 黑棋 AI 一手 | < 0.1s | < 0.5s |
| 白棋 AI 一手 | < 1s | < 5s |
| 单手上限 | 30s (可调) | 60s (可调) |
